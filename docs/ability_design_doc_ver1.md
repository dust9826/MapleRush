## 1. 능력 시스템 공통 규칙

본 문서의 5종 능력은 모두 `player_design_doc_ver3.md` §4의 공통 규칙을 상속한다.

| 항목 | 규칙 | 출처 |
|---|---|---|
| 슬롯 | 단일 1개 (동시 1능력 보유) | player §4.2 |
| **발동 조작** | **마우스 휠 클릭(가운데 버튼)을 직접 눌러 발동** — 5종 전부 공통 | player §4.3 |
| 사용 횟수 | 일반 스테이지 1회 / 보스 스테이지 2회; 스테이지 진입 시 초기화 | player §4.4 |
| 교체 | 새 능력 획득 시 기존 능력 즉시 소멸·교체(단방향), 교체 전 확인 UI | player §4.2·§4.7 |
| 슬로우 모션 중 처리 | 능력 발동·지속·횟수 소모는 **실제 시간(Wall-clock) 기준**(`ElapsedSeconds` 차분); 슬로우(0.25배) 영향 없음 | player §3.2.2 |
| 스테이지 전환·재시작 | 진행 중인 지속형 능력 효과는 **강제 해제**; 사용 횟수 재초기화 | stage §2.3.5 단일 초기화 함수 |
| 미보유·소진 시 | 입력은 항상 수신하되 무시 처리 + UI 피드백 | player §4.7 |
| 능력 생성물의 패링 | 능력이 만들어내는 모든 판정·투사체(일섬 베기, 회전베기, 반사 투사체 등)는 **플레이어 생성물 → 적의 패링 대상이 아님** | player §5.5·§7.4 |

## 2. 능력 목록 개요

| 역할 | # | 능력 이름 | 한 줄 효과 | 공격 판정 패링 가능 |
|---|---|---|---|---|
| 🛡️ 방어 | 1 | **임시 무적** | 발동 후 **1초간** 모든 피해 무효 | — (공격 아님) |
| 🛡️ 방어 | 2 | **모든 투사체 무효화** | 화면 내 모든 적 투사체 즉시 제거 | — (공격 아님) |
| 🛡️ 방어 | 3 | **부동심 (응급 회생)** | 일정 시간 내 **적의 공격 1회 무효화**(수동 보험) | — (공격 아님) |

## 3. 방어 능력 상세

### 3.1 임시 무적

| 항목 | 내용 |
|---|---|
| 발동 | **마우스 휠 클릭으로 직접 발동**(능동). 발동 즉시 효과 적용 |
| 효과 | 발동 후 **1초간 모든 피해 무효** (적 근접 공격·투사체 등 1피격 즉사 판정 전부 무시) |
| 발동 중 행동 | 무적 상태에서도 이동·평타·대시·다른 입력 모두 정상 사용 가능(무적은 유지) |
| 강화 방향 | 지속 시간 증가 |

**예외 처리**

> - 지속 시간 **1초는 Wall-clock 기준**으로 측정하며 슬로우 모션(0.25배)의 영향을 받지 않는다.
> - 무적 도중 평타·대시를 사용해도 무적은 강제 해제되지 않으며, **1초 경과 시 즉시 해제**된다.
> - 스테이지 진입·이탈·재시작 시 진행 중이던 무적은 강제 해제(stage §2.3.5).
> - 능력 미보유/사용 횟수 소진 시 휠 클릭 입력은 무시 + UI 피드백.

### 3.2 모든 투사체 무효화

| 항목 | 내용 |
|---|---|
| 발동 | 마우스 휠 클릭으로 직접 발동. 즉시 발동형(지속 시간 없음) |
| 효과 | 발동 순간 **화면(뷰포트) 내 모든 적 투사체를 즉시 제거** |
| 강화 방향 | 제거 범위 확장(화면 밖 투사체 포함) / 제거 시 범위 내 적에게 추가 데미지 |

**예외 처리**

> - 제거 대상은 **적 투사체 한정**이다. 플레이어가 반사한 투사체·짱돌 등 **아군 생성물은 제거하지 않는다**.
> - 즉시 발동형이므로 지속 시간·중첩 개념이 없다.
> - 보스 투사체도 화면 내라면 제거 대상에 포함(보스 본체는 영향 없음).

### 3.3 부동심 (응급 회생)

| 항목 | 내용 |
|---|---|
| 발동 | 마우스 휠 클릭으로 직접 발동(능동 발동, 효과는 수동 트리거형 보험) |
| 효과 | 발동 후 **8초간 적의 공격 1회를 무효화**한다. 무효화 발생 시 → 자동 소모 + **0.5초 무적** 부여 + **슬로우 모션 1초** 발동. 8초 내 적의 공격을 받지 않으면 효과 소멸(능력 사용 횟수는 소모됨) |
| 강화 방향 | 보험 지속 창(8초) 증가 / 무효화 가능 횟수 +1 / 무효화 시 주변 적 넉백(또는 보스 그로기 게이지 충전) |

**예외 처리**

> - "적의 공격 1회 무효화"의 대상은 **근접 공격·투사체 모두 포함**한다(색상 무관, 빨간색 공격도 무효화 대상).
> - 무효화 직후 0.5초 무적으로 동일 프레임·연속타에 의한 추가 사망을 방지한다.
> - 무효화 시 발동되는 슬로우 모션 1초는 기존 슬로우 시스템(0.25배, player §3.2)을 재사용하며, **수동적 보험을 반격 기회로 전환**하는 장치다.
> - 보험 창(8초)·무적(0.5초)·슬로우(1초)는 모두 **Wall-clock 기준**.
> - 스테이지 진입·이탈·재시작 시 "보험 플래그"를 강제 초기화(stage §2.3.5).
> - **[차별점]** 임시 무적은 "오는 공격을 알 때 정면 돌파"(능동·예측 필요), 부동심은 "언제 올지 모르는 한 방에 대한 보험"(수동·예측 불필요). 시간축이 다르므로 동시 채택 시에도 역할이 겹치지 않는다.

## 4. 공격 능력 상세

### 4.1 만지 일섬

| 항목 | 내용 |
|---|---|
| 발동 | 마우스 휠 클릭으로 발동. **돌진 방향 = 발동 시점의 커서 방향** |
| 효과 | 커서 방향으로 직선 돌진하며 **돌진 경로 위 모든 적에게 `공격력 × 400%`** (기본값 기준 40) |
| 돌진 거리 | **6 world unit (직선)** — 능력 전용 거리(대시와 독립적으로 설정; 능력 특성상 대시보다 넉넉하게 이동) |
| 판정 범위 | 돌진 경로를 따라 **좌우 반지름 1 world unit**의 캡슐(직선)형 판정 |
| 돌진 시간 | **0.1초** |
| 무적(i-frame) | **돌진 시간(0.1초) 전체 동안 무적** — 기존 대시의 "이동 시간 = 무적 시간" 원칙과 동일 (player §3.1.2) |
| 대시 횟수 | **소모하지 않음** (대시 스탯과 무관) |
| 공격 판정 패링 | **❌ 불가** — 일섬 판정은 패링 트리거가 아니다 |
| 강화 방향 | 데미지 증가 / 돌진 거리·판정 폭 증가 / 보스 명중 시 그로기 게이지 추가 충전 |

**예외 처리**

> - 돌진 중 플레이어는 **돌진 궤적에 고정**된다(자유 이동 불가; 일반 대시와 동일 동작).
> - 돌진 시간(0.1초)·무적은 **Wall-clock 기준**으로 슬로우 모션 영향 없음.
> - 일섬 판정은 플레이어 생성물이므로 적의 패링 대상이 아니며, **일섬 자체도 적 공격을 패링하지 않는다**(공격형 능력 중 패링 가능한 것은 회전베기뿐 — §5.1).
> - 보스 명중 시 그로기 게이지는 일반 공격과 동일하게 "명중 데미지량만큼" 충전(강화 옵션 선택 시 추가) — stage §1.4.2.
> - **벽(플랫폼) 충돌 시 돌진 정지**(플랫폼 통과 불가) — 기존 대시 판정과 동일하게 처리한다.

### 4.2 회전베기

| 항목 | 내용 |
|---|---|
| 발동 | 마우스 휠 클릭으로 발동(방향 무관, 플레이어 중심 광역) |
| 효과 | **플레이어 중심 반지름 3 world unit 원형** 내 모든 적에게 `공격력 × 250%`(기본값 25) + **넉백(1 world unit 밀어냄)** |
| 지속·무적 | 발동 후 **0.2초간** 회전 판정 지속, 그 동안 플레이어 **무적** |
| **이동 가능 여부** | **❌ 불가** — 0.2초 지속 동안 플레이어는 이동할 수 없다(이동 잠금). 데미지는 적당 1회만 적용 |
| 공격 판정 패링 | **✅ 가능 (5종 중 유일)** — 아래 별도 항목 참조 |
| 강화 방향 | 반지름 증가 / 데미지 증가 / 범위 내 적 투사체(빨강 포함) 동시 소멸 |

**패링 판정 상세 (회전베기 전용)**

> 0.2초 회전 판정이 지속되는 동안, 반지름 3 범위 내로 진입한 **적의 노란색(`parryable=true`) 공격/투사체**에 대해 패링이 발동된다(player §5 패링 시스템 준용):
> - **근접 노란 공격** → 무효화
> - **노란 투사체** → 반사(`공격력 × 200%`, 기본 20; 명중 대상 무관 통일 — player §5.4.2)
> - **보스 한정** → 패링/반사 성립 시 그로기 게이지 충전(`공격력 × 100%`의 2배 = 20; 반사는 명중 시점 — stage §1.4.2)
> - **빨간색(`parryable=false`) 공격**은 패링되지 않으며, 0.2초 무적으로만 회피된다.

**예외 처리**

> - `공격력 × 250%` 광역 데미지와 패링/반사는 **같은 발동의 별개 효과**로, 동시에 적용된다(둘 다 발생 가능).
> - 넉백은 **적 대상**(피격 적을 플레이어 반대 방향으로 **1 world unit** 밀어냄)이며 투사체에는 적용하지 않는다(노란 투사체는 반사로 처리).
> - 반사된 투사체는 플레이어에게 재피격되지 않는다(아군 면제 — player §5.5).
> - 0.2초 회전·무적·패링 판정은 **Wall-clock 기준**(슬로우 무관).
> - 스테이지 전환·재시작 시 진행 중이던 회전베기는 강제 종료(stage §2.3.5).
> - **[설계 의도]** 공격형 능력 중 회전베기만 패링이 가능하도록 한정한다 — "회전하는 칼날이 사방의 공격을 받아쳐 무효화·반사"하는 컨셉으로, 공격과 방어를 겸하는 유일한 하이브리드 능력이다.

## 5. 능력 ↔ 기존 시스템 상호작용

### 5.1 패링 가능 여부 (요약)

| 능력 | 공격 판정으로 적 공격 패링 가능? | 비고 |
|---|---|---|
| 임시 무적 | — | 공격 판정 없음 |
| 모든 투사체 무효화 | — | 공격 판정 없음(제거는 패링과 별개) |
| 부동심 | — | 공격 판정 없음 |
| 만지 일섬 | **❌ 불가** | 일섬 판정은 패링 트리거 아님 |
| 회전베기 | **✅ 가능** | 5종 중 유일 (§4.2 패링 판정 상세) |

> 기존 규칙과 일관: 평타만 패링 가능하고 **대시 공격으로는 패링 불가**(player §5.5). 능력 판정도 기본적으로 패링 트리거가 아니며, **회전베기만 의도적 예외**로 패링 판정을 수행한다.

### 5.2 슬로우 모션 상호작용

- 5종 능력의 발동·지속·횟수 소모는 모두 **Wall-clock 기준**으로, 슬로우 모션(0.25배) 중에도 정상 시간으로 동작한다(player §3.2.2).
- 부동심 무효화 시 발동되는 **슬로우 1초**는 기존 슬로우 시스템(`SetClientTimeScale(0.25)` + 서버 적·투사체 감속)을 재사용한다(player §3.2.5).

### 5.3 스테이지 초기화 연동

지속형 효과를 가진 능력은 `stage_design_doc_ver3.md` §2.3.5 **단일 초기화 함수**의 "강제 해제" 목록에 다음을 추가해야 한다:

- 임시 무적 잔여 무적(2초) 해제
- 부동심 보험 플래그(8초 창) 초기화
- 회전베기 진행 중 회전 판정(0.3초)·무적 종료
