# MapleRush 전 층 완주 타임 랭킹 기능명세서

> 문서 상태: 기획 초안  
> 개발 범위: 현재 구현된 기록·리더보드 기능의 정리 및 표시 개선  
> 제외: 개인/글로벌 러쉬 기록, 콤보 랭킹, 직업·캐릭터별 랭킹, 신규 허브·세계관 콘텐츠

## 1. 목표

랭킹은 MapleRush를 끝까지 완주한 플레이어의 **전투 시간**을 비교하는 공식 기록판이다. 완주 여부와 시간만으로 명확하게 경쟁하도록 만들며, 미완주 진행도나 반복 플레이 횟수는 글로벌 순위에 섞지 않는다.

## 2. 현재 구현 검토

현재 프로젝트에는 이미 `RecordStorage`, `RunTimer`, `RankingBasic`, `LobbyController`를 연결한 글로벌 리더보드가 있다.

### 2.1 현재 동작

| 항목 | 현재 구현 |
| --- | --- |
| 시간 측정 | `RunTimer`가 전투 스테이지 활성 구간만 누적. 보상·노드·상점·전환·사망 구간은 정지 |
| 완주 기록 | 마지막 층 보스 클리어 시 `bestClearTime`에 더 빠른 시간을 저장 |
| 런 종료 기록 | 게임 오버와 전 층 클리어 모두 `SubmitRun` 실행 |
| 리더보드 제출 | 모든 런 종료 때 현재 최고 완주 시간과 누적 플레이 횟수를 인코딩해 제출 |
| 순위 우선순위 | 완주자 우선 → 빠른 완주 시간 우선 → 같은 시간은 누적 플레이 횟수 많은 쪽 우선 |
| 미완주자 | 완주자 아래에 누적 플레이 횟수 순으로도 글로벌 목록에 표시 가능 |
| 화면 | 로비 진입 시 내 순위와 상위 10개 행을 요청·표시 |

### 2.2 현재 구현의 유지할 점

- 실제 전투 시간만 계산하는 `RunTimer`의 기준
- 더 빠른 완주 시간만 개인 최고 기록으로 저장하는 `bestClearTime`
- 로비 진입 시 상위 10위와 내 순위를 조회하는 흐름
- `RankingBasic` 패키지를 이용한 글로벌 저장·조회 구조

## 3. 변경 기능 명세

### 3.1 기록 조건

| 항목 | 변경 후 명세 |
| --- | --- |
| 글로벌 등록 대상 | 현재 구성된 모든 층을 클리어한 런만 등록 |
| 기록 시간 | `RunTimer`의 전투 시간 합계 |
| 제외 시간 | 스테이지 선택, 보상 선택, 상점, 전환·로딩, 사망·결과 화면 등 비전투 시간 |
| 개인 최고 기록 | 더 빠른 완주 시간일 때만 `bestClearTime` 갱신 |
| 미완주 런 | 로컬 진행도 기록만 갱신하고, 글로벌 랭킹에는 제출하지 않음 |

### 3.2 순위 규칙

1. 완주 시간이 짧을수록 높은 순위다.
2. 시간은 0.01초 단위로 저장하고 표시한다.
3. 완전히 같은 시간은 공동 순위로 표시한다.
4. 공동 순위 이후의 목록 정렬은 먼저 등록된 기록을 앞에 둔다.
5. 플레이 횟수, 콤보 등급, 처치 수, 직업, 캐릭터 정보는 순위 산정에 사용하지 않는다.

### 3.3 로비 화면 명세

기존 로비의 기록 영역과 리더보드 텍스트 영역을 유지하고, 내용만 아래처럼 정리한다.

| 영역 | 표시 내용 |
| --- | --- |
| 제목 | `전 층 완주 기록` |
| 내 기록 | 내 최고 완주 시간과 내 순위 |
| 미완주 상태 | `아직 완주 기록이 없습니다.` |
| 상위 목록 | 상위 10명의 순위, 플레이어명, 완주 시간 |
| 빈 목록 | `아직 등록된 완주 기록이 없습니다.` |
| 안내 문구 | `스테이지 선택·상점 시간은 기록에 포함되지 않습니다.` |

- 완주 기록이 10개보다 적으면 실제 기록만 표시한다.
- 미완주 횟수, 콤보, 캐릭터 정보는 목록에 노출하지 않는다.
- 별도의 개인 러쉬 보드·글로벌 러쉬 보드·콤보 보드는 추가하지 않는다.

## 4. 현재 구현 대비 변경점

| 구분 | 현재 | 변경 후 | 필요한 조치 |
| --- | --- | --- |
| 글로벌 제출 시점 | 게임 오버와 완주 모두 제출 | 전 층 완주 시에만 제출 | `SubmitRun`에서 글로벌 제출을 `fullClear` 조건으로 분리 |
| 미완주 기록 | 플레이 횟수 점수로 글로벌 목록 하위에 포함 | 글로벌 목록에서 완전히 제외 | `EncodeRankScore`의 미완주 점수 경로 제거, 게임 오버 시 제출 호출 제거 |
| 동점 기준 | 누적 플레이 횟수가 많은 쪽 우선 | 같은 시간은 공동 순위, 등록 시각으로 표시 순서만 결정 | 플레이 횟수 하위 자릿수 인코딩 제거, 랭킹 모드/정렬 정책 확인 |
| 랭킹 점수 | 완주 플래그 + 역순 시간 + 플레이 횟수 | 완주 시간만 비교할 수 있는 점수 | `RANK_PLAY_MOD`, `totalRuns` 의존을 리더보드 경로에서 제거 |
| 목록 행 | 완주 시간과 플레이 횟수, 또는 `미완주 (n판)` | 플레이어명과 완주 시간만 | `RequestLeaderboard`의 행 생성 로직 수정 |
| 내 순위 | 미완주 상태에서도 순위가 생길 수 있음 | 완주 기록이 있는 경우에만 표시 | 미완주자는 `0` 순위와 안내 문구 반환 |
| 로컬 진행도 | 층·스테이지·최고 진행 기록 저장 | 유지 | `bestScore`, `BestFloor`, `StageBests`는 로컬 자기 기록용으로 유지 |

## 5. 데이터 및 이행 계획

### 5.1 유지 데이터

| 데이터 | 유지 이유 |
| --- | --- |
| `bestClearTime` | 완주 타임 랭킹과 내 최고 기록의 핵심 데이터 |
| `bestScore`, `BestFloor`, `BestStageInFloor`, `BestPhase`, `BestTime` | 미완주 포함 로컬 자기 기록과 HUD의 이전 기록 표시 |
| `StageBests` | 스테이지 단위 이전 기록 표시 |

### 5.2 랭킹 경로에서 제거할 의존

| 데이터/상수 | 처리 |
| --- | --- |
| `totalRuns` | 플레이 통계 또는 로컬 데이터로 남길 수 있으나, 랭킹 점수·표시에는 사용하지 않음 |
| `RANK_PLAY_MOD` | 랭킹 점수 인코딩에서 제거 |
| `DecodeRankPlayCount` | 리더보드 표시에서 제거 |
| 미완주 점수 | 생성·제출하지 않음 |

기존에 저장된 미완주자의 글로벌 점수는 새 점수를 등록하기 전까지 남아 있을 수 있다. 배포 시에는 랭킹 주기를 새로 시작하거나, 기존 리더보드 데이터를 초기화해 완주 기록만 보이게 정리한다. 이 선택은 운영 권한이 필요한 작업이므로 개발 구현과 분리해 진행한다.

## 6. 구현 순서

1. `RecordStorage.SubmitRun`을 로컬 기록 처리와 글로벌 제출 처리로 분리한다.
2. 전 층 완주일 때만 `bestClearTime`을 갱신·저장하고 리더보드에 제출한다.
3. 랭킹 점수에서 플레이 횟수 자릿수를 제거하고, 시간 기준 점수로 단순화한다.
4. 순위 패키지의 동점 처리 방식이 공동 순위를 지원하도록 설정 또는 보완한다.
5. `RequestLeaderboard`가 완주 행만 반환하게 수정하고, 행에서 플레이 횟수와 미완주 문구를 제거한다.
6. `LobbyController`의 제목·내 기록·빈 상태 문구를 새 명세에 맞춰 수정한다.
7. 기존 리더보드의 미완주 데이터 처리 방식(새 주기 시작 또는 초기화)을 운영 결정 후 적용한다.

## 7. 검증 기준

- 게임 오버를 여러 번 해도 글로벌 리더보드에 새 행이나 순위가 생기지 않는다.
- 전 층 완주 후에만 내 순위와 상위 목록에 기록이 반영된다.
- 보상·상점·선택 화면에서 보낸 시간은 완주 시간에 포함되지 않는다.
- 상위 10위는 빠른 완주 시간 순으로 표시된다.
- 같은 완주 시간은 같은 순위로 표시된다.
- 목록에 플레이 횟수, 미완주 문구, 콤보 정보가 나타나지 않는다.
- 기존 로컬 진행도·스테이지 기록 표시는 유지된다.
