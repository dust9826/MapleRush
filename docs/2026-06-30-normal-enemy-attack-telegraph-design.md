# 일반 적 공격 예고(Attack Telegraph) — 설계

- 날짜: 2026-06-30 / 작성: HyeonMoKim0 (+ Claude)
- 관련: MR-G(적 AI 상태패턴) 인접 · 참고: `2026-06-28-enemy-attack-box-judgment-and-telegraph-gizmo-design.md`(보스 공격 예고)

## 한 줄 요약

일반 적(근접·원거리)의 공격을 플레이어가 미리 보고 피하거나 패링하도록, **"어디에·언제 맞는지"를 알리는 공격 예고 표시**를 출시 빌드에 추가한다. 새 게임플레이가 아니라 **이미 있는 판정·타이밍 데이터를 플레이어가 볼 수 있게 노출**하는 작업이다.

## 1. 현황 — 무엇이 됐고 무엇이 없나

| 구성 | 상태 |
|---|---|
| 적 예비동작 타이밍 (근접 windup 0.6s / 원거리 aim 1.0s) | ✅ 출시 포함 |
| 명중 판정 (근접 전방 박스 / 원거리 투사체) | ✅ 출시 포함 |
| 서버→클라 데이터 경로 (근접 브로드캐스트 / 원거리 `@Sync IsAiming`) | ✅ 구현됨 |
| **플레이어용 공격 예고 시각 표시 (출시)** | ⬜ **없음 ← 본 기획 대상** |

- 지금 플레이어가 보는 "예고"는 **적의 공격 애니메이션 클립뿐** — 공격이 어느 공간에 떨어질지는 안 보인다.
- 공간 예고(박스/레인)는 보스 작업(2026-06-28)에서 만들었으나 **`DrawGizmo` 디버그 스위치에 묶여 출시 빌드에선 꺼진다**(서버 전송부터 차단). → 출시용으로 따로 살려야 함.

## 2. 보스 예고에서 계승할 규칙

- **근접** = 적 정면 AABB 박스 · **원거리** = 적→플레이어 회전 레인(플레이어 추적).
- **색**: 노랑 = 패링 가능/예고, 빨강 = 명중 임박/패링 불가.
- **세로 회피**: 박스 윗변을 점프·위대시 높이보다 낮게(이미 `EnemyMeleeBoxHeight`에 반영).
- 차이: 보스 건 *디버그 외형* → 본 기획은 **채움(진행도) + 색 전환**으로 플레이어용 승격.

## 3. 설계

### 공통 원칙

1. 출시 빌드에서 항상 ON — 디버그(`DrawGizmo`)와 분리된 게이트 `ShowAttackTelegraph`(기본 true).
2. 데이터 = 서버 권위 / 표시 = 클라 전용(로컬 플레이어 한정).
3. **"언제" = 채움**: 표시 등장 ~ 명중/발사까지 진행도만큼 차오르고, 가득 차는 순간 = 맞는/쏘는 순간.
4. **"대응법" = 색**: 노랑 → 임박 시 빨강(색만 전환, **점멸 없음**).
5. 표시 위치·크기 = 실제 판정과 동일 좌표(불일치 금지).

### 3.1 근접 적 (`EnemyMelee`)

- **표시**: windup 동안 적 정면 노랑 박스. 위치/크기는 이미 등록되는 `pendingAttack`(`center/hw/hh`) 그대로.
- **채움**: `elapsed/windup`만큼 박스가 차오름.
- **색**: 잔여 windup ≤ `TelegraphImminentThreshold` → 빨강. (패링 불가 공격은 처음부터 빨강 — 현재 일반 근접 적은 패링 가능이라 노랑.)

### 3.2 원거리 적 (`EnemyRanged`)

- **표시**: aim 동안(`IsAiming`) 적→플레이어 노랑 레인. 방향은 클라가 매 프레임 플레이어 추적.
- **채움**: `elapsed/aim`만큼 적→플레이어로 차오름. → 진행도용 `@Sync number AimStartElapsed` 추가 필요.
- **색**: 발사 임박 시 빨강.

### 3.3 구현 방식 = A안 (확정)

- `GizmoManager`의 검증된 retained-mode 라인 홀더 패턴 재사용(맵 자식 스폰 + Points 1회 bake + 매 프레임 Transform만 갱신). 리스크·작업량 최소.
- **채움**: 외곽선 박스/레인 위에 "채움 홀더"를 1개 더 겹쳐, 진행도만큼 `Scale`을 0→full로 늘림.
- **추상화**: `TelegraphMeleeBox(center,hw,hh,fill,isRed)` / `TelegraphRangedLane(origin,dir,len,w,fill)` 의미 메서드로 분리(추후 스프라이트 방식 교체 대비). B안(스프라이트/데칼)은 폴리시 단계 옵션.

## 4. 색 규칙

점멸 없음 — "언제"는 채움이, "대응법"은 색이 전달.

| 상태 | 색 |
|---|---|
| 예고 중(패링 가능) | 노랑 + 채움 차오름 |
| 임박(잔여 ≤ 임계값) | 빨강(색만 전환) |
| 패링 불가 공격 | 빨강(처음부터) |

## 5. 영향 / 데이터

게임플레이(판정·FSM·타이밍)는 **무변경**. 표시 레이어만 추가.

| 파일 | 변경 |
|---|---|
| `Core/GameConstants.mlua` | `ShowAttackTelegraph` 게이트 + 색/알파/임박임계값/풀크기 상수 |
| `Core/CombatPrimitives.mlua` | 근접 브로드캐스트 게이트를 `DrawGizmo` → 출시 게이트로 분리 |
| `Enemy/EnemyRanged.mlua` | `@Sync AimStartElapsed` 추가(채움 진행도용) |
| `Player/`(신규) | 출시용 텔레그래프 소스 컴포넌트 + 표시 매니저(GizmoManager 패턴 복제) |

- 모양 치수(`EnemyMeleeBoxForward/Height`, `GizmoRangedLaneLength/Width`)는 **기존 상수 재사용**(판정과 일치).

## 6. 검증 (Maker play, map02)

- `DrawGizmo=false`(출시 모사)에서도 예고가 보인다.
- 근접: windup에 노랑 박스 차오름 → 임박 시 빨강 → 판정 좌표 = 표시 좌표 일치.
- 원거리: aim에 레인이 플레이어 추적 + 차오름 → 발사 직전 빨강 → 발사 방향 일치.
- 패링: 노랑 구간 평타로 무효화/반사 정상. 빌드·런타임 에러 0.

## 7. 결정 / 잔여

- **확정**: ① A안(라인 재사용) · ② 채움 연출 포함 · ③ 점멸 없음(색 전환만).
- **구현 시 확정**: 표시 매니저 위치(디버그 분리 위해 신규 전용 권장) · 채움 방향 축 · 풀 크기(동시 적 수 실측).
